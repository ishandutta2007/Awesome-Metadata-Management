# 🔎 Overview



Metadata Management platforms provide a central system for understanding **what data exists, what it means, where it came from, who owns it, how it is used, how trustworthy it is, and what policies apply to it**.



Modern metadata platforms increasingly combine:



* Data Catalog

* Data Discovery

* Business Glossary

* Technical Metadata

* Business Metadata

* Data Lineage

* Column-Level Lineage

* Data Classification

* Sensitive Data Discovery

* Data Quality

* Data Observability

* Data Ownership

* Data Stewardship

* Data Contracts

* Data Products

* Policy Management

* Access Governance

* Search

* Impact Analysis

* Data Marketplace

* Knowledge Graphs

* Semantic Metadata

* AI/LLM Context

* Metadata APIs

* Metadata-as-Code



This ecosystem can broadly be divided into:



```text

                    METADATA MANAGEMENT

                           │

          ┌────────────────┴────────────────┐

          │                                 │

   SaaS / Hosted                      Open Source

          │                                 │

  ┌───────┼────────┐              ┌─────────┼─────────┐

  │       │        │              │         │         │

Catalog Governance Lineage      Catalog   Lineage   Governance

  │       │        │              │         │         │

Atlan   Collibra Alation       DataHub  OpenLineage Atlas

Purview Informatica            OpenMetadata Egeria ODD

DataGalaxy OvalEdge            Gravitino Marquez CKAN

```



Open-source is particularly important because metadata management is increasingly becoming a **shared infrastructure layer** rather than merely a catalog UI.

```text
        │                │                 │

        │

        ├── Search

        ├── Glossary

        ├── Classification

        ├── Quality

        ├── Graph

        ├── Policies

        └── AI Context

```
